# 数字分身部署指南

## 前置条件

- Node.js >= 20
- DSH (DeepSeek Harness) 已安装
- Git

## 安装步骤

### 1. 克隆仓库

```bash
# 在统一的目录下克隆（例如 D:\Woker\packages）
cd D:\Woker\packages
git clone https://github.com/lomehong/dsh-memory.git
git clone https://github.com/lomehong/dsh-im-bot.git
```

### 2. 安装依赖并构建

```bash
# ── dsh-memory ──
cd D:\Woker\packages\dsh-memory
npm install
npx tsc -b tsconfig.json
node scripts/build-client.mjs

# ── im-channel ──
cd D:\Woker\packages\dsh-im-bot\im-channel
npm install
npx tsc -b tsconfig.json

# ── ui-settings-im ──
cd D:\Woker\packages\dsh-im-bot\ui-settings-im
npm install
npx tsc -b tsconfig.json
node scripts/build-client.mjs

# ── persona-guide ──
cd D:\Woker\packages\dsh-persona-guide
npm install
npx tsc -b tsconfig.json
node scripts/build-client.mjs
```

### 3. 配置 DSH Profile

编辑 `~/.dsh/profiles/web/package.json`：

```json
{
  "name": "dsh-profile-web",
  "private": true,
  "dependencies": {
    "@dsh-extra/im-channel": "file:D:\\Woker\\packages\\dsh-im-bot\\im-channel",
    "@dsh-extra/dsh-client-ui-settings-im": "file:D:\\Woker\\packages\\dsh-im-bot\\ui-settings-im",
    "@dsh-extra/dsh-memory": "file:D:\\Woker\\packages\\dsh-memory",
    "@dsh-extra/dsh-persona-guide": "file:D:\\Woker\\packages\\dsh-persona-guide"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "@dsh-extra/im-channel",
        "@dsh-extra/dsh-client-ui-settings-im",
        "@dsh-extra/dsh-memory",
        "@dsh-extra/dsh-persona-guide"
      ]
    }
  }
}
```

> **注意：** `file:` 路径要改成实际克隆的目录。

### 4. 配置 cordis.patch.yml

编辑 `~/.dsh/profiles/web/cordis.patch.yml`：

```yaml
# ── 数字分身：罗拉 ──────────────────────────────────────────────────────
- id: system-prompt
  config:
    persona: >-
      你是罗拉的数字分身，由 {{model}} 模型驱动。

      你的身份：罗拉（公司副总裁）的专属 AI 协作伙伴。你了解她的工作背景、管理风格和个人偏好，以她的视角思考问题，用她的风格沟通表达。

      你的角色：一个务实、高效的 AI 搭档。你不是在「服务」罗拉，而是在「协作」——你提供专业分析和建议，她做最终决策。你们是有商有量的伙伴关系。

      你的工作范围：涵盖人力资源、审计、信息安全、总裁办等管理领域的文档处理、方案分析、决策支持、跨部门协调等事务。

      沟通风格：直接、务实、结构化。先说结论/建议，再展开依据。善用分点、表格、对比等结构化呈现方式。不用长篇大论，不啰嗦。

- id: skill-filesystem
  config:
    directories:
      - ~/.dsh/skills

- id: agent-presets
  config:
    default: digital-twin
```

### 5. 创建技能目录

```bash
mkdir -p ~/.dsh/skills/{management,personal,templates}
```

### 6. 创建设置文件

编辑 `~/.dsh/settings.yaml`：

```yaml
agent-default-model:
  provider: aicc
  model: ep-20260813165219-8j4dbqj
agent-presets:
  default: digital-twin
im-channel:
  channels:
    wecom-1:
      kind: wecom
      enabled: true
      displayName: 企业微信机器人 1
```

### 7. 配置企业微信凭证

在 `~/.dsh/im-channel/credentials/wecom.json` 中：

```json
{
  "botId": "你的BotID",
  "secret": "你的Secret"
}
```

### 8. 配置 MCP 工具

在 `~/.dsh/im-channel/credentials/mcp-servers.json` 中：

```json
{
  "servers": [
    {
      "name": "企业微信待办",
      "type": "streamable-http",
      "url": "https://qyapi.weixin.qq.com/mcp/v2/bot/todo?apikey=...",
      "enabled": true,
      "id": "mcp_todo"
    }
  ]
}
```

### 9. 创建分身指引文档目录

```bash
mkdir -p D:\Woker\docs
```

将 `数字分身搭建框架.md` 放到该目录下。

### 10. 启动 DSH

```bash
dsh web
```

## 完整文件清单

```
~/.dsh/
├── profiles/web/
│   ├── package.json          # 插件注册
│   ├── cordis.patch.yml      # 人设 + 技能 + 预设
│   └── node_modules/         # npm install 后自动生成
├── im-channel/credentials/
│   ├── wecom.json             # 企业微信 BotID/Secret
│   ├── wecom-mcp.json         # MCP 工具配置
│   ├── mcp-servers.json       # 通用 MCP 服务器
│   └── shared-memory.json     # 共享记忆数据（自动创建）
├── .agent-presets/digital-twin/
│   ├── agent.cordis.yml       # 分身预设
│   └── preset.yml             # 显示名称
├── skills/
│   ├── management/            # 管理类技能
│   ├── personal/              # 个人类技能
│   └── templates/             # 模板
└── settings.yaml              # 全局设置
```

## 一键初始化脚本

也可以创建一键脚本 `setup-persona.ps1`：

```powershell
param(
    [string]$PackagesDir = "D:\Woker\packages",
    [string]$BotId = "",
    [string]$Secret = ""
)

# 1. 克隆仓库
Write-Host "=== 克隆仓库 ==="
git clone https://github.com/lomehong/dsh-memory.git "$PackagesDir\dsh-memory"
git clone https://github.com/lomehong/dsh-im-bot.git "$PackagesDir\dsh-im-bot"

# 2. 构建
Write-Host "=== 构建插件 ==="
cd "$PackagesDir\dsh-memory"
npm install; npx tsc -b tsconfig.json; node scripts/build-client.mjs

cd "$PackagesDir\dsh-im-bot\im-channel"
npm install; npx tsc -b tsconfig.json

cd "$PackagesDir\dsh-im-bot\ui-settings-im"
npm install; npx tsc -b tsconfig.json; node scripts/build-client.mjs

# 3. 创建目录
Write-Host "=== 创建目录 ==="
mkdir -p "$HOME\.dsh\im-channel\credentials"
mkdir -p "$HOME\.dsh\skills\management"
mkdir -p "$HOME\.dsh\skills\personal"
mkdir -p "$HOME\.dsh\skills\templates"
mkdir -p "$PackagesDir\docs"

# 4. 写入凭证
if ($BotId -and $Secret) {
    @{ botId = $BotId; secret = $Secret } | ConvertTo-Json | Set-Content "$HOME\.dsh\im-channel\credentials\wecom.json"
}

Write-Host "=== 完成 ==="
Write-Host "请手动配置 package.json 和 cordis.patch.yml（见部署指南）"
