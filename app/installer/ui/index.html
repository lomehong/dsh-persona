欢迎使用 DSH 数字分身

本向导会引导你完成 DSH 数字分身的安装与配置：便携版运行环境、分身人设、桌面应用与快捷方式。

  • 自动下载并安装便携版 Node.js + DSH（无需管理员权限、不影响系统 Node）
  • 一键克隆并构建 dsh-memory / dsh-im-bot / dsh-yuyi / dsh-persona-guide 插件
  • 写入数字分身预设（人设、称呼、别名），随时可在 DSH 设置中调整
  • 下载并安装 DSH Desktop 桌面宿主，创建桌面「数字分身」快捷方式

建议在安装前关闭企业微信 / 浏览器等可能占用 3080 端口的程序。
